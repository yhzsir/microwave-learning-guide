# 微波技术基础 · 在线学习指南

一套面向《微波技术基础》（32 学时）课程的**完整中文学习指南网站**，包含知识点详解、公式推导、例题精解、考点分析与自测题库，可直接作为 GitHub Pages 站点访问。

> 依据大连理工大学赵楠教授《微波技术基础》（辽宁省一流线下课程）的课件体系编写，覆盖 **绪论、均匀传输线理论、规则金属波导、微波传输线、微波网络基础、微波无源器件** 六章正文，外加 **无耗网络 $[Z]$ 矩阵** 与 **网络对称性** 两个专题推导。

## 技术特点

| 特性 | 实现方式 |
|---|---|
| **零构建依赖** | 纯静态 HTML/CSS/JS，无需 npm、无需打包器，GitHub Pages 直接托管 |
| **数学排版** | MathJax 3（SVG 输出）。构建前用「数学保护器」把 `$...$` / `$$...$$` 抽成占位符，避免 Markdown 解析破坏下划线、星号与竖线 |
| **离线可用** | 每个章节页的内容以 `<script type="text/plain">` 预嵌入，页面不依赖 `fetch`。即使 MathJax CDN 不可达，公式源码仍完整可读 |
| **全文搜索** | 构建时按 `##`/`###` 切片生成索引（200+ 条），支持中英文与 LaTeX 片段检索，`Ctrl + K` 唤起 |
| **交互工具** | 自研 Canvas 史密斯圆图：拖动即读归一化阻抗、导纳、反射系数、驻波比、波腹/波节值 |
| **主题与无障碍** | 亮/暗双主题（跟随系统 + 记忆偏好）、语义化标签、`aria-label`、焦点可见、`prefers-reduced-motion` 支持 |
| **打印友好** | 独立打印样式，自动隐藏导航，公式与图表避免跨页断裂 |

## 本地使用

直接双击 `index.html` 即可浏览（内容已内嵌，无需服务器）。若要启用搜索与视频，请启动本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://127.0.0.1:8000
```

### 重新构建

修改 `content/*.md` 后，运行生成器刷新 HTML 外壳、导航、目录与搜索索引：

```powershell
powershell -ExecutionPolicy Bypass -File tools/build.ps1
```

### 校验

```bash
node tools/test-render.js    # 渲染管线测试（Markdown → HTML、公式保护、提示框、表格）
node tools/lint-content.js   # 内容结构校验（LaTeX 配对、SVG id 唯一性、标签合法性）
```

## 内容规范

`AUTHORING.md` 定义了全部写作规范，包括：

- **front matter** 字段（`chapter` / `title` / `short` / `desc` / `minutes`）
- **公式语法**：只用 `$...$` 与 `$$...$$`，编号用 `\tag{章-节-序号}`
- **自定义提示框**（9 类，渲染为彩色信息面板）：

  | 标签 | 用途 | 颜色 |
  |---|---|---|
  | `> **【核心概念】**` | 定义、本质、物理图像 | 蓝 |
  | `> **【公式推导】**` | 推导过程 | 紫 |
  | `> **【例题 N-M】**` | 完整例题 | 绿 |
  | `> **【考点】**` | 考试重点与题型 | 橙 |
  | `> **【易错点】**` | 常见错误与混淆 | 红 |
  | `> **【工程应用】**` | 实际系统中的应用 | 青 |
  | `> **【记忆技巧】**` | 口诀与类比 | 黄 |
  | `> **【思考】**` | 引导性问题 | 灰 |
  | `> **【小结】**` | 要点归纳 | 深蓝 |

- **图形**：统一使用内联 SVG，配色引用 CSS 变量（`var(--brand)` 等），保证双主题可读
- **符号统一表**：$Z_0$、$\gamma=\alpha+j\beta$、$\Gamma$、$\rho$、$k_c$、$\lambda_g$ 等

## 八章要点速览

**第 1 章 绪论**　微波频段（300 MHz–3000 GHz / 0.1 mm–1 m）、五大特点、趋肤效应、长线判据、三种分析方法（路→2 章 / 场→3 章 / 网络→5 章）。

**第 2 章 均匀传输线理论**（核心）　电报方程 → $Z_0$、$\gamma$、$v_p$ → $Z_{\mathrm{in}}(z)$、$\Gamma$、$\rho$ 三大状态参量 → 行波/驻波/行驻波完整分析 → 波腹波节位置 → 史密斯圆图 → 阻抗匹配（λ/4 变换器、单枝节调配器）。

**第 3 章 规则金属波导**（核心）　亥姆霍兹方程与横向场关系式 → TE/TM 模式 → 截止波数与截止波长 → TE$_{10}$ 主模场结构与五条主模理由 → 波导波长/相速/群速/波阻抗 → 尺寸选择三原则 → 圆波导 → 激励与耦合。

**第 4 章 微波传输线**　同轴线 TEM 场与三个最佳 $b/a$（1.65 / 3.59 / 50 Ω）→ 带状线 → 微带线准 TEM、有效介电常数与 Hammerstad 公式 → 耦合微带线奇偶模 → 介质波导与光纤。

**第 5 章 微波网络基础**　等效传输线与归一化 → $[Z]$/$[Y]$/$[A]$/$[S]$ 四矩阵的定义、测量条件、转换、级联 → 无耗↔幺正、互易↔对称。

**第 6 章 微波无源器件**　终端元件、连接元件、衰减器与相移器 → 螺钉调配器与阶梯阻抗变换器 → 三端口不能同时匹配的证明 → E-T/H-T/双 T/魔 T 的 $[S]$ 矩阵与四条性质。

**第 7、8 章 专题推导**　$[Z]^+=-[Z]$ 的完整证明；$z_{11}=z_{22}\Rightarrow S_{11}=S_{22}$ 的完整证明；互易与对称的严格区分。

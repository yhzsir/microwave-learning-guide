## 三、题型解法模板

### 3.1 计算题：输入阻抗类

**通用四步**：

1. **算 $\beta$**：$\beta=\dfrac{2\pi}{\lambda}=\dfrac{2\pi f}{v}=\dfrac{2\pi f\sqrt{\varepsilon_r}}{c}$。介质填充时**不要漏掉 $\sqrt{\varepsilon_r}$**。
2. **算 $\beta z$**（用弧度；注意 $0.75\pi$ 这类值就是最简形式，不必换成小数）。
3. **代公式**：$Z_{\mathrm{in}}=Z_0\dfrac{Z_l+jZ_0\tan\beta z}{Z_0+jZ_l\tan\beta z}$。分子分母**同时**约去 $Z_0$ 后可用归一化形式 $\bar z_{\mathrm{in}}=\dfrac{\bar z_l+j\tan\beta z}{1+j\bar z_l\tan\beta z}$ 减少运算量。
4. **化简为 $a+jb$**，说明结果呈感性还是容性。

> **【易错点】**
> $\tan\beta z$ 在 $\beta z=\pi/2$ 处发散（对应 $\lambda/4$，输入阻抗无穷大即开路），此时不能直接代入，要用 $\lambda/4$ 变换性 $Z_{\mathrm{in}}=Z_0^2/Z_l$。

### 3.2 计算题：反射系数与驻波比类

1. $\Gamma_l=\dfrac{Z_l-Z_0}{Z_l+Z_0}$，化为**模与相位**形式 $|\Gamma_l|e^{j\varphi_l}$（这是后续求波腹位置的必需量）。
2. $\Gamma(z)=\Gamma_le^{-j2\beta z}$，只改相位不改模。
3. $\rho=\dfrac{1+|\Gamma_l|}{1-|\Gamma_l|}$。
4. 若要求 $Z_{\mathrm{in}}$：$Z_{\mathrm{in}}=Z_0\dfrac{1+\Gamma(z)}{1-\Gamma(z)}$。

**复数除法的模与相位**：$\left|\dfrac{a}{b}\right|=\dfrac{|a|}{|b|}$，$\arg\dfrac ab=\arg a-\arg b$。用这一条可以避免展开复数除法。

### 3.3 计算题：波腹/波节点位置

1. 由 $\Gamma_l$ 求出 $\varphi_l$ 的**主值**（$-180^\circ<\varphi_l\le180^\circ$）。
2. $z_{\max}=\dfrac{\varphi_l\lambda}{4\pi}+\dfrac{n\lambda}{2}$，取 $n$ 使 $z_{\max}$ 为**最小正值**。
3. $z_{\min}=z_{\max}\pm\dfrac{\lambda}{4}$，同样取最小正值。
4. **验算**：$z_{\max}$ 与 $z_{\min}$ 之差必为 $\lambda/4$，且 $Z_{\mathrm{in}}(z_{\max})=Z_0\rho$、$Z_{\mathrm{in}}(z_{\min})=Z_0/\rho$ 均为纯电阻，两者乘积应为 $Z_0^2$。

> **【记忆技巧】**
> 分情形记忆最快：**纯电阻负载**只有两种——$R_l<Z_0$ 时负载处即**电压波节**（$z_{\min}=0$、$z_{\max}=\lambda/4$）；$R_l>Z_0$ 时负载处即**电压波腹**（$z_{\max}=0$、$z_{\min}=\lambda/4$）。感性负载的第一波腹点向负载侧偏移（$0<z_{\max}<\lambda/4$），容性负载向电源侧偏移（$\lambda/4<z_{\max}<\lambda/2$）。

### 3.4 计算题：波导类

1. **先判单模**：算 $\lambda_c(\mathrm{TE}_{10})=2a$，比较工作波长 $\lambda_0$ 与 $2a$、$a$。
2. **算 $\lambda_g$**：$\lambda_g=\dfrac{\lambda_0}{\sqrt{1-(\lambda_0/\lambda_c)^2}}$。注意根号内必须是**正数**，否则该模式被截止。
3. **算 $v_p$、$v_g$**：$v_p=\dfrac{c}{\sqrt{1-(f_c/f)^2}}$、$v_g=\dfrac{c^2}{v_p}$。
4. **算波阻抗**：TE 取 $\dfrac{\eta}{\sqrt{1-(f_c/f)^2}}$，TM 取 $\eta\sqrt{1-(f_c/f)^2}$。

**尺寸设计题**的答题顺序（按重要性）：①单模传输 $\lambda/2<a<\lambda$；②功率容量（$a$、$b$ 尽量大）；③衰减（$b$ 大则衰减小但要防 TE$_{01}$）；④机械与工艺限制。工程取值 $a\approx0.7\lambda$、$b\approx0.4\sim0.5a$。

### 3.5 证明题：网络性质类

| 要证明的结论 | 起手式 | 关键步骤 |
|---|---|---|
| 网络无耗 | 写 $P_{av}=\frac12\mathrm{Re}[\mathbf{I}^T[Z]\mathbf{I}^*]=0$ | 分对角项（令其他电流为零）与交叉项（只留两个电流）讨论 |
| $[Z]^+=-[Z]$ | 同上 | 交叉项展开实部得 $a(R_{mn}+R_{nm})+b(X_{nm}-X_{mn})=0$，由 $a,b$ 独立得 $R_{mn}=-R_{nm}$、$X_{mn}=X_{nm}$ |
| 网络互易 | 洛伦兹互易定理 $\nabla\cdot(\mathbf E_1\times\mathbf H_2-\mathbf E_2\times\mathbf H_1)=0$ | 推出 $\sum_i(U_i^{(1)}I_i^{(2)}-U_i^{(2)}I_i^{(1)})=0$，代入 $a,b$ 表示得 $S_{ij}=S_{ji}$ |
| 网络无耗（用 $[S]$） | 功率守恒 $\sum|a_i|^2=\sum|b_i|^2$ | 对任意 $a$ 成立 → $[S]^+[S]=[I]$ |
| $S_{11}=S_{22}$ | 由 $[S]=([z]+[E])^{-1}([z]-[E])$ 展开 $2\times2$ | 代入 $z_{11}=z_{22}$，分子分母完全相同 |
| 三端口不能同时匹配 | 设 $S_{11}=S_{22}=S_{33}=0$ | 幺正条件给三个模平方和为 1 → 每个 $=1/2$；正交条件要求至少两个为零 → 矛盾 |

> **【考点】**
> 证明题的得分点分布通常是：**起手式（写对出发点）2–3 分、关键中间步骤 3–5 分、结论 1–2 分**。即使推不到最后，把正确的出发方程与已知条件写全也能拿到一半分。**不要空白。**

### 3.6 简答题：概念辨析类

高频简答的"标准答案骨架"：

- **空心波导为何无 TEM 波**：TEM 要求 $E_z=H_z=0$ → 横向场可由二维拉普拉斯方程的标量势 $\varphi$ 描述（$\nabla_t^2\varphi=0$）→ 金属壁为等势面 → 单导体边界下边值问题只有平凡解 → 故不存在。**结论：TEM 波必须由双导体支撑。**
- **为什么 TE$_{10}$ 是主模**：① 截止波长最长（$2a$），单模带宽最宽；② 场结构最简单，易于激励与耦合；③ 宽边中央无纵向壁电流，可开缝用于测量与馈电；④ 衰减较小；⑤ 单模传输避免模式色散与模式耦合。
- **为什么 $v_p>c$ 不违反相对论**：相速描述的是等相位面的移动速度，不承载能量与信息；能量传播速度是群速 $v_g<c$，且 $v_pv_g=c^2$。
- **为什么 $\lambda_g>\lambda_0$**：波在波导中"曲折传播"，沿轴向的有效波长被拉长，$\lambda_g=\lambda_0/\sin\theta>\lambda_0$（$\theta$ 为射线与轴线的夹角）。
- **互易与对称的区别**：互易是 $S_{12}=S_{21}$，来源是媒质各向同性；对称是 $S_{11}=S_{22}$，来源是结构几何对称。两者独立。
- **衰减为何先降后升**：分子 $R_s\propto\sqrt f$ 随频率增长；分母 $\sqrt{1-(f_c/f)^2}$ 在 $f\to f_c$ 时趋于零使衰减发散。两者竞争产生最小值。

## 五、考场策略

1. **先扫全卷再动笔**（约 3 分钟）。标记出必得分题与难题，规划顺序。
2. **按"计算 → 简答 → 证明"的顺序答题**。计算题有明确步骤、分步给分，性价比最高；证明题留到最后，但要**写满起手式与关键步骤**。
3. **分步书写、公式先行**。每个计算题先写出所用公式（即使数值算错也有公式分），再代入数值。
4. **单位与量纲必须写**。$\Omega$、$\mathrm{GHz}$、$\mathrm{mm}$、$\mathrm{rad/m}$、$\mathrm{Np/m}$、$\mathrm{dB}$——漏单位的扣分非常常见。
5. **数值结果给三位有效数字**，并**说明性质**（"结果呈容性""该模式被截止""能单模传输"）。这类结论性表述往往是独立的给分点。
6. **验算三个自洽关系**：
   - $Z_{\mathrm{in}}(z_{\max})\cdot Z_{\mathrm{in}}(z_{\min})=Z_0^2$
   - $v_pv_g=c^2$（无耗空气填充）
   - $\rho=\dfrac{1+|\Gamma_l|}{1-|\Gamma_l|}$ 与 $|\Gamma_l|=\dfrac{\rho-1}{\rho+1}$ 互为反函数
7. **圆图题一定要画出旋转方向与角度**，并在图上标出工作点。即使读数有误差，作图步骤也能得分。
8. **证明题切忌跳步**。每一步都写"由……得……"，尤其是"因为 $a,b$ 独立取值，故各项系数分别为零"这类关键论据——这是评分点。
